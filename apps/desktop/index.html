Models

Train outside this app, then export with export_deploy_weights.py using required --checkpoint and --output paths; place the gzip file in wsi-fungal-segmentation/models/.

Run training on a workstation or cluster using wsi-fungal-segmentation/scripts/train.py and wsi-fungal-segmentation/configs/default.yaml (same layout as on main). Export tiles with the QuPath script under qu-path-scripts/ when building datasets. Default dataset path is training_data/MASTERTILE at the repository root.

After training, export is a separate step: the script only accepts --checkpoint (full training .pth with model_state_dict) and --output (path for the gzip deploy file). Example from wsi-fungal-segmentation:

Terminal commands (from repository root)
cd wsi-fungal-segmentation
pip install -r requirements.txt
python scripts/train.py --config configs/default.yaml
python scripts/export_deploy_weights.py \
  --checkpoint checkpoints/best_model.pth \
  --output models/deploy-fungus.pth.gz

Adjust --checkpoint to your saved weights. You can also write --output elsewhere and copy the .pth.gz (or .pt.gz) into wsi-fungal-segmentation/models next to the app, then refresh the list below.
